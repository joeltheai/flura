# flura

Open `index.html` in your browser. No install, build step, or server.

Swipe between Chords, Arp, and Flower. Tap play to start sound.

JavaScript lives in `app.js` (interface), `music.js` (chords and lanes), `audio.js` (sound), and `flower.js` (3D flower). The local Three.js library and its license are in `vendor/`.
